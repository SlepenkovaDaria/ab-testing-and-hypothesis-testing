Два учебных проекта по анализу данных и проверке статистических гипотез на Python.

1. A/B-тест платёжной формы
Анализ конверсии в успешную оплату: подготовка данных, проверка платёжной воронки, z-тест для долей и доверительный интервал. В текущих расчётах новая форма показала конверсию выше на 14,62 п. п. (требуется уточнить полноту выборки).

3. Одновыборочный t-тест
Проверка гипотезы о среднем весе продукции: описательная статистика, критерий Шапиро — Уилка, t-тест Стьюдента и моделирование Монте-Карло.

Стек: Python, Pandas, NumPy, SciPy, Statsmodels, Matplotlib.
